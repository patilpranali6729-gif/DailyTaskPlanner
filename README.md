# Daily Task Planner

## Project 02 - Web Development

A simple responsive Daily Task Planner built using HTML5, CSS3, JavaScript and Bootstrap 5.

### Features
- Current date display
- Add task
- Add task using Enter key
- Edit task
- Complete / pending toggle
- Delete task
- All / Pending / Completed filters
- Task counters
- Clear completed tasks
- localStorage data persistence
- Responsive Bootstrap layout

### Technologies
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

### How to Run
1. Extract the ZIP file.
2. Open the `DailyTaskPlanner` folder.
3. Open `index.html` in a browser.
4. Add and manage tasks.

No backend or database is required.
